# 🥬 韭菜養成所：少年股神的一生 (Twitch Streamer Stock Simulator)

這是一款專為**實況主與聊天室互動**量身打造的台股迷因生存模擬遊戲！手握 100 萬本金，在 30 個交易日的殘酷修羅場中，體驗歐印暴富、慘遭主力養套殺、接到營業員奪命連環摳，最後光榮登頂或住進大都會公園第一排的完整人生。

---

## 🎮 遊戲核心特色 (Game Features)

- **🔥 零手動輸入，純按鈕直覺單挑**：免敲鍵盤，透過 `-10萬`、`+10萬`、`+50萬`、`半倉` 與 `🔥歐印` 快捷鍵迅速建倉，支援「賣出一半」與「全數出清」一鍵變現，絕對不卡單！
- **📈 50/50 巨浪狂暴盤面**：單日波動極劇烈，隨時可能迎來「利多出盡大戶倒貨」或「利空出盡強力軋空」的反市場心理戰。
- **🩺 即時三色動態心電圖 (ECG Monitor)**：
  - 🟢 **平穩 (綠色)**：賺錢時心率平緩，伴隨沉穩心跳聲。
  - 🟤 **緊張 (棕色)**：浮虧時心率加快。
  - 🔴 **恐慌 (紅色)**：大賠時波形狂飆，心跳聲如機關槍般急促。
  - 💀 **歸零 (直線)**：血本無歸時心電圖直接變成死亡長鳴。
- **📞 營業員（小美）奪命連環摳**：總資產跌破 30 萬時，無預警強制跳出 Margin Call 追繳警報。
- **🤣 圖奇靈魂咆哮語音 (TTS)**：盤後戰報結合爆笑荒謬的操盤真相（如「老董喝大冰奶」、「主力便當排骨掉地上砸盤」），並以高速機關槍台味語音直接朗讀。
- **🎁 觀眾自訂股票彩蛋**：點開下拉選單最下方，可隨時輸入聊天室觀眾點名的神祕飆股與代號！

## 🕹️ 如何遊玩 (How to Play)

1. 進入遊戲後，輸入你的**實況主 ID**（實名制開戶）。
2. 點選橫條常駐的 9 大熱門焦點股（0050、台積電、陽明、合一等）或從下拉選單挑選標的。
3. 點選按鈕設定下單金額，按下 **做多 (Long)** 或 **放空 (Short)** 進場單挑。
4. 點擊「刪 App 裝死一天」或「迎接下一天」推進天數，看你能否在 30 天內成為全台第一少年股神！

## 🛠️ 技術架構 (Tech Stack)
- **HTML5 / CSS3**（動漫風粗框、高對比、自適應配置）
- **Vanilla JavaScript**（無須安裝任何套件，單一 `index.html` 完美運行）
- **Web Audio API**（合成心跳音效、開盤喜悅琶音、錯愕滑稽下行音）
- **Web Speech Synthesis API**（實況主實時 TTS 語音播報）
